# Contributing

Thanks for your interest in patchsprite-sniffer.

## Contributor license agreement (CLA)

A CLA is required before a pull request can be merged. The CLA text is still a draft and is not published yet. When it is ready, CLA Assistant will be set up on this repository and will ask you to sign it on your first pull request.

The CLA applies to every part of this repository, including the shared engine package (`packages/engine`, coming soon). The project's copyright holder also uses that package in its own products, which the CLA allows. Pull requests to it are not merged without a signed CLA.

## What not to submit

- No vendor files, firmware, or vendor software.
- No device mappings (parameter maps, offset tables, or similar).
